# 比价台 · 本地自动抓价

输入商品名称，用本机 Chrome 自动打开淘宝、京东、拼多多的搜索页，提取商品标题、价格、店铺和销量，把三家结果汇总成一张表，支持按价格、匹配度或平台排序，也支持筛选平台。

抖音商城目前没有稳定的电脑版商城搜索入口，因此自动版只抓三家。

## 快速开始

环境要求：Node.js 20+（推荐 22）和 Chrome 或 Edge。项目不需要安装 npm 依赖。

1. 双击 `start-auto.bat`，或在当前目录运行：

```powershell
node server.mjs
```

2. 浏览器会打开 `http://127.0.0.1:8787/`。
3. 点击页面上的「逐家登录」。登录面板会先显示淘宝二维码，登录完成后点「下一家：京东」，再登录拼多多。每次只打开当前平台的一个登录页，前一家登录态会保留在本机的 `.chrome-profile`。
4. 回到比价页，输入商品名称，点「抓取价格」。
5. 三家的结果会边抓边汇总到表格。抓取前会先点平台的「价格」排序；需要登录、验证码或页面结构变化时，平台卡片会显示原因和「打开这个页面处理」按钮，处理完点「重新抓取」。

第一次启动 Chrome 和登录页可能需要 10–20 秒，之后浏览器进程会复用，通常会快很多。

关闭本地服务时双击 `stop-auto.bat`，或关闭运行 `node server.mjs` 的命令行窗口。

## 手动版

如果不想登录，或自动抓取被平台风控拦截，可以打开 `http://127.0.0.1:8787/manual`，用原来的人工搜索 + 回填价格方式比价。也可以直接双击 `index.html` 打开手动版。

## 实现方式

- 本地 Node HTTP 服务，只监听 `127.0.0.1:8787`
- 通过 Chrome DevTools Protocol 控制一个专用 Chrome
- 登录 Cookie 保存在 `.chrome-profile`，不上传到任何第三方服务器
- 三个搜索页并行打开，结果通过 NDJSON 流式返回，先完成先显示
- 抓取前先按价格从低到高排序，汇总表可以再按价格高低、匹配度或平台排序
- 价格里出现 `x`、`X`、`?`、`？` 时按 `0` 参与数字排序，但表格仍显示原始字符（例如 `1xxxx` 排序值为 `10000`，展示仍为 `1xxxx`）

项目没有使用 Playwright、Puppeteer 或第三方爬虫接口，只依赖 Node 内置模块和本机 Chrome。

## 界面风格

页面按项目根目录的 `DESIGN.md` 实现（NerdWallet-inspired）：深绿主色、薄荷色分区、近直角按钮、细线表格和少量柠檬绿强调色。手动版与自动抓价版共用同一套设计变量，桌面和手机宽度都已适配。

## 已知限制

三个平台都要求登录，并且会根据账号、地区、设备和访问频率触发验证码或风控：

- 淘宝可能要求滑块或安全验证
- 京东可能跳到「京东验证」中间页
- 拼多多可能要求手机号/微信登录，网页版商品结构也可能随时调整

自动抓取依赖平台页面结构，平台改版后可能需要更新 `server.mjs` 里的 `PLATFORMS` 选择器。抓取到的是搜索页展示价，不等于最终到手价；优惠券、会员、地区库存和运费都会影响结算价。

请把它当作个人本机比价工具使用，控制抓取频率，并遵守各平台的服务条款。

## 常见问题

**页面提示「本地抓取服务未连接」**

确认 `start-auto.bat` 的窗口还开着，或运行 `node server.mjs`；如果 8787 端口被占用，可以指定其他端口：

```powershell
$env:PORT=8790; node server.mjs
```

**一直显示需要登录**

点击「逐家登录」，按淘宝、京东、拼多多的顺序完成登录；如果登录后仍提示，点卡片的「打开这个页面处理」，确认页面已经是登录状态，再点「重新抓取」。

**找不到 Chrome**

安装 Chrome，或先设置环境变量：

```powershell
$env:CHROME_PATH="C:\Program Files\Google\Chrome\Application\chrome.exe"; node server.mjs
```

**想清空登录态**

先关闭抓取浏览器，再删除项目下的 `.chrome-profile` 目录。下次抓取会重新要求登录。

**无界面测试**

```powershell
$env:HEADLESS=1; $env:NO_OPEN=1; node server.mjs
```

`HEADLESS=1` 时无法手动扫码登录，只适合调试页面状态。

## 文件

- `server.mjs`：本地服务、Chrome CDP、搜索页抓取和解析
- `auto.html` / `auto.css` / `auto.js`：自动抓价页面
- `index.html` / `styles.css` / `app.js`：手动比价页面
- `start-auto.bat`：Windows 一键启动
- `.chrome-profile/`：登录态和浏览器缓存，首次运行后生成
